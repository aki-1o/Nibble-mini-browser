A variable named after a top-level field overwrites that field when the request is sent, so a dashed chip changes the body even though no {{token}} appears in it. // and /* */ comments (and the trailing commas they leave behind) are stripped before sending, so you can keep lines commented out.

NameValue

Use as {{name}} in the URL, headers, body, and API key.

Inject a URL param

New keys go to the front of the query string, right after the host; existing keys are updated in place. The URL in the top bar reloads.

Account Aggregator

Added to the JSON body when the request is sent. If the body already has an accountAggregatorId, this value replaces it.

The AA is a build-time choice in the SDK — Context.setStrategy() imports AAServices/$REACT_APP_AACLASS, so one deployed host serves one AA. If the build's AA does not match the id sent at init, decodeParam fails. The ?aaId query param does not switch AA logic; it only picks the S3 config path and branding. The selected AA's short code is applied to the journey URL as aaId; it is different from accountAggregatorId.

Tenant

The SDK routes in priority order, so a lower number wins. The AA is baked into a deployment at build time; the tenant is chosen per URL.

Routing rules

These are the conditions the SDK routes on, not every param it accepts. Clicking one injects it into the URL bar, merging with whatever is already there so fi, reqdate and ecreq survive — decryptURL() needs all three, so a URL built from scratch never renders.
